# Chrome Web Store visual assets

The store listing visual set contains the following files:

- `propwise-extension-popup.webp`: the actual PropWise popup preview populated with a representative listing, indicative price, location score, Analyze action, and Save locally action.
- `propwise-home.png`: the public landing page showing the product value proposition.
- `propwise-workspace.png`: the authenticated workspace overview.
- `propwise-pin-analysis.png`: the map-first analysis workflow with the exact-pin requirement.
- `propwise-dashboard.png`: the authenticated dashboard shell and research activity view.
- `propwise-login.png`: the dedicated secure login experience.

Use the popup preview as the primary extension screenshot and the website screenshots as supporting product-context screenshots in the Chrome Web Store dashboard. Before submission, replace development URLs in the extension source with the published PropWise website URL and publish a public privacy-policy page.
